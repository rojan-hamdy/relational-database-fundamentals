# Self-Test — Authorization and Authentication

**Q1. What is authentication?**

<details>
<summary>Show answer</summary>
Authentication is the process of verifying a user or principal’s identity.
</details>

**Q2. What is authorization?**

<details>
<summary>Show answer</summary>
Authorization is the process of deciding what an authenticated user is allowed to do.
</details>

**Q3. What is the difference between a login and a user in SQL Server?**

<details>
<summary>Show answer</summary>
A login is a server-level principal, while a user is a database-level principal mapped to a login.
</details>

**Q4. What does GRANT do?**

<details>
<summary>Show answer</summary>
GRANT gives a user or role permission to perform an action.
</details>

**Q5. What does REVOKE do?**

<details>
<summary>Show answer</summary>
REVOKE removes previously granted permissions.
</details>

**Q6. What does DENY do?**

<details>
<summary>Show answer</summary>
DENY explicitly prevents a user from performing an action, even if other permissions might exist.
</details>

**Q7. Why is least privilege important?**

<details>
<summary>Show answer</summary>
It reduces risk by limiting users to the minimum permissions they need.
</details>

**Q8. What is the main purpose of roles?**

<details>
<summary>Show answer</summary>
Roles group permissions so they can be assigned consistently to multiple users.
</details>

---

## Quick revision

- Authentication = identity verification
- Authorization = permission enforcement
- Login = server identity
- User = database identity
- Permissions = SELECT, INSERT, UPDATE, DELETE, EXECUTE, etc.
