# Self-Test — CREATE, ALTER, DROP

**Q1. Which command creates a database object?**

<details>
<summary>Show answer</summary>
CREATE.
</details>

**Q2. Which command changes an existing database object?**

<details>
<summary>Show answer</summary>
ALTER.
</details>

**Q3. Which command deletes an object?**

<details>
<summary>Show answer</summary>
DROP.
</details>

**Q4. Why is DROP dangerous?**

<details>
<summary>Show answer</summary>
Because it removes the object and can delete its structure and data permanently.
</details>

**Q5. Which command is used to add a new column to a table?**

<details>
<summary>Show answer</summary>
ALTER TABLE ... ADD ...
</details>

**Q6. Which DDL command would you use to create a new table?**

<details>
<summary>Show answer</summary>
CREATE TABLE.
</details>

---

## Quick revision

- CREATE = define new object
- ALTER = modify object
- DROP = remove object
