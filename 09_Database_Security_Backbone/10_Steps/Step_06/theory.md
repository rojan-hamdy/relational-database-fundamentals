# Security Backbone — Step 06

## Step 06 — Secure data in transit and at rest

Security is not only about login controls. Data also needs to be protected while stored and while moving across networks.

### Common controls
- TLS for client-server traffic,
- encrypted backups,
- database encryption where supported,
- secure storage for logs and files.

### SSMS method
- Review backup storage locations.
- Check whether backups are encrypted.
- Verify database encryption options in supported editions.

### Key idea
Data is vulnerable both while moving and while stored.
