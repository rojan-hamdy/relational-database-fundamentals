# Self-Test — Built-in Functions (String, Date, Math, System)

**Q1. What are built-in SQL functions used for?**

<details>
<summary>Show answer</summary>
They simplify common tasks such as string processing, date arithmetic, system lookups, and mathematical calculations.
</details>

**Q2. Which function returns the current date and time?**

<details>
<summary>Show answer</summary>
GETDATE().
</details>

**Q3. Which function converts text to uppercase?**

<details>
<summary>Show answer</summary>
UPPER().
</details>

**Q4. Which function calculates the number of characters in a string?**

<details>
<summary>Show answer</summary>
LEN().
</details>

**Q5. Which function returns the current database name?**

<details>
<summary>Show answer</summary>
DB_NAME().
</details>

**Q6. Why are built-in functions useful in SQL queries?**

<details>
<summary>Show answer</summary>
They reduce manual logic and make queries cleaner and more readable.
</details>

## Quick revision

- String = UPPER, LOWER, CONCAT, LEN
- Date = GETDATE, DATEDIFF, DATEADD
- Math = ROUND, ABS, SQRT, POWER
- System = DB_NAME, USER_NAME, @@VERSION
