# Self-Test — Aggregate Functions

**Q1. What do aggregate functions do?**

<details>
<summary>Show answer</summary>
They combine many values into a single summary value.
</details>

**Q2. Which function counts rows?**

<details>
<summary>Show answer</summary>
COUNT().
</details>

**Q3. Which function totals values?**

<details>
<summary>Show answer</summary>
SUM().
</details>

**Q4. Which function finds the average?**

<details>
<summary>Show answer</summary>
AVG().
</details>

**Q5. Which functions return the smallest and largest values?**

<details>
<summary>Show answer</summary>
MIN() and MAX().
</details>

**Q6. Why are aggregate functions important in analytics?**

<details>
<summary>Show answer</summary>
They allow quick summary reporting such as totals, averages, and counts.
</details>

---

## Quick revision

- COUNT = number of rows
- SUM = total
- AVG = average
- MIN = lowest value
- MAX = highest value
