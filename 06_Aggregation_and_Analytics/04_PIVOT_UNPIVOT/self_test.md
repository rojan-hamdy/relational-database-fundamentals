# Self-Test — PIVOT & UNPIVOT

> Status: ✅ Ready for practice.

**Q1. What does PIVOT do?**

<details>
<summary>Show answer</summary>
PIVOT converts row-based values into column-based summary values.
</details>

**Q2. What does UNPIVOT do?**

<details>
<summary>Show answer</summary>
UNPIVOT converts column-based values back into rows.
</details>

**Q3. Why is PIVOT helpful in reporting?**

<details>
<summary>Show answer</summary>
It makes cross-tab reports easier to read and compare.
</details>

**Q4. In which case would UNPIVOT be useful?**

<details>
<summary>Show answer</summary>
When you need to normalize a wide table back into a tall format.
</details>

**Q5. What is the main difference between pivoting and grouping?**

<details>
<summary>Show answer</summary>
Grouping summarizes by categories, while pivoting changes the orientation of the result set.
</details>

**Q6. Which option is more suitable for a matrix report?**

<details>
<summary>Show answer</summary>
PIVOT.
</details>

---

## Quick revision

- PIVOT = rotate rows into columns
- UNPIVOT = rotate columns into rows
